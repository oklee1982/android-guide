# 第1个月｜计划-第2周

## 周主题与目标
- 主题：Android Studio + Gradle 项目结构入门、Activity/Fragment 生命周期与导航、ViewBinding 与传统 View 布局。
- 目标：能在 Android Studio 中从零创建一个包含 3 个 Activity + 1 个 Fragment 的示例 App，完成 Intent 跳转、生命周期日志、ViewBinding/RecyclerView 结合、基本状态保存与 README 运行说明。
- 验收：`app/week2-sample/` 目录下提交 Demo 工程（含截图、APK、README）；完成生命周期/导航图、问题清单；日更日志与错题记录。

## 准备事项（周一上午前）
- 安装或更新 Android Studio Giraffe+，配置 SDK、AVD（API 34）与真机调试证书。
- 创建基础仓库结构：`app/week2-sample/`（Android 工程）、`notes/week2/`（讲义/复盘）、`assets/screenshots/`（页面截图）。
- 预先生成 AI Prompt 模板：IDE 配置指南、Gradle 脚本讲解、生命周期讲义、代码审查、复盘模板。
- 检查 JDK（17）与 Gradle Wrapper 版本，记录在 `notes/week2/env.md`。

## 每日节奏提醒
- 1h AI 讲义/面试问答 → 4h 编码/调试 → 1h Bug/错题复盘 → 1h 文档/截图整理 → 1h 面试或巩固练习。
- 每个功能提交至少 1 次 Git commit，并在日志中写明“已知/未知/验证点”。

## 每日拆解

### 第1天（周一）｜Android Studio + Gradle 基础
- **学习**：Android Studio 界面、Gradle 项目结构、模块与 `build.gradle.kts`、Manifest、资源目录。
- **实操**：
  1. 使用 Empty Activity 模板创建 `week2-sample` 工程，整理包结构 `ui/main`, `ui/detail`, `data`.
  2. 在 `notes/week2/ide-setup.md` 记录 IDE/AVD/真机配置与常用快捷键。
  3. 运行默认应用，抓取首次构建日志、Gradle Task 图。
- **AI 提示词**：
  - `请用表格讲解 Android Studio 主界面（Project/Gradle/Logcat 等面板）的用途，并附3个常见配置错误与排查。`
  - `以下是我的 build.gradle.kts，请指出 compileSdk/minSdk/buildFeatures 应如何配置才能启用 ViewBinding。`
- **复盘产出**：IDE 配置指南、Gradle 关键字段速查表、构建问题列表。

### 第2天（周二）｜Activity & Intent
- **学习**：Activity 生命周期（onCreate→onStart→onResume...）、显式/隐式 Intent、`startActivityForResult`(API33 之前) 与 `ActivityResultLauncher`、Manifest 声明。
- **实操**：
  1. 实现 `MainActivity` + `DetailActivity`，添加 Intent Extras、返回结果。
  2. 通过 `Logcat` & 自建 `LifecycleLogger` 记录生命周期回调，保存到 `notes/week2/lifecycle-log.md`。
  3. 在 README 写入运行步骤与“生命周期观测”截图。
- **AI 提示词**：
  - `请生成 Activity 生命周期 vs 回调用途的对照表，并附2个涉及配置更改的情景题。`
  - `根据以下 Intent 需求，生成 Kotlin 示例代码与注意事项（含新 API 的 Activity Result API 写法）。`
- **复盘产出**：生命周期图（ASCII 或 Mermaid）、Intent 流程描述、常见崩溃排查表。

### 第3天（周三）｜常用 View 组件与 ConstraintLayout
- **学习**：`TextView`、`Button`、`ImageView`、`EditText`、`RecyclerView` 之前的 `LinearLayout`/`ConstraintLayout` 布局思路、`MaterialCardView`/`Toolbar` 常见属性、资源抽取（`colors`/`dimens`/`styles`）。
- **实操**：
  1. 设计“课程信息卡”页面：标题、副标题、封面图、CTA 按钮，练习 ConstraintLayout 约束、Guideline、Chain。
  2. 编写 `FormActivity`，包含 `TextInputLayout + EditText + Button`，做输入校验与错误提示；记录在 `notes/week2/ui-basics.md`。
  3. 在 `notes/week2/view-cheatsheet.md` 汇总常用 View 的属性、示例及常见坑，并附两张布局截图。
- **AI 提示词**：
  - `请用表格对比 TextView/Button/ImageView/EditText 的常用属性，并给出 ConstraintLayout 约束示例。`
  - `根据以下布局草图，生成 ConstraintLayout XML，并说明如何提取 dimens/colors 提升复用。`
- **复盘产出**：UI 组件速查表、ConstraintLayout 示例代码、`FormActivity` 输入校验测试记录。

### 第4天（周四）｜ViewBinding + RecyclerView
- **学习**：ViewBinding 启用方式、Activity/Fragment 中的使用范式、生命周期注意事项；`RecyclerView`/Adapter 架构、`ViewHolder`、`DiffUtil`（进阶）、点击事件封装。
- **实操**：
  1. 在 `MainActivity` 中启用 ViewBinding，封装 `BindingActivity` 基类，复用 Day3 布局组件。
  2. 创建“课程列表”页面：`RecyclerView` + `CourseAdapter`，支持点击项跳转到 `DetailActivity`。
  3. 输出 `notes/week2/viewbinding-cheatsheet.md`，涵盖 Activity/Fragment、Adapter 中的 Binding 写法与防止内存泄漏技巧；为 `CourseAdapter` 编写 `DiffUtil` 测试或断言。
- **AI 提示词**：
  - `请讲解 ViewBinding 的启用步骤、Activity/Fragment/Adapter 中的常见写法与注意事项，并附 Kotlin 示例。`
  - `根据以下数据模型，生成 RecyclerView Adapter 骨架并指出列表更新策略（DiffUtil/submitList）。`
- **复盘产出**：ViewBinding 决策表、课程列表运行截图、`CourseAdapter` 测试日志。

### 第5天（周五）｜Fragment + 导航
- **学习**：Fragment 生命周期、`FragmentManager`、`FragmentContainerView`、BackStack、`supportFragmentManager.commit`、简单导航图（进阶：可选 Navigation Component 初识）。
- **实操**：
  1. 在 `MainActivity` 中嵌入 `DashboardFragment`，支持按钮切换到 `DetailFragment`。
  2. 在 `notes/week2/navigation.md` 绘制页面/Fragment 导航关系图。
  3. 记录 Fragment 生命周期对比表，整理常见坑（`childFragmentManager`、`viewLifecycleOwner`）。
- **AI 提示词**：
  - `请生成 Fragment 生命周期 vs Activity 生命周期对照表，并解释 viewLifecycleOwner 的意义。`
  - `以下是我的 Fragment 切换需求，请提供 commit/replace/add/backStack 场景的建议做法。`
- **复盘产出**：Fragment 模板代码、导航图、问题清单更新。

### 第6天（周六）｜状态管理 + 联调与周总结
- **学习**：`ViewModel`、`onSaveInstanceState`、`SavedStateHandle` 协作流程；配置变更测试策略；Logcat 过滤与 ADB 常用命令、打包/签名概览、周总结写法。
- **实操**：
  1. 在 `DetailActivity` 或 `DetailFragment` 中加入 ViewModel/SavedStateHandle，处理屏幕旋转后的状态恢复；实现设置页或对话框，通过 `ActivityResultLauncher` 或 Fragment Result API 回传数据。
  2. 使用 `layout-land`/`values-land` 验证资源适配，在 `notes/week2/state-handling.md` 绘制“配置变更→状态恢复”流程；记录测试矩阵。
  3. 运行 `./gradlew assembleDebug`，完成 Demo 联调并录制操作视频或截图组合；编写 `notes/week2-summary.md`，整理错题与 `issues-week2.md`。
- **AI 提示词**：
  - `请讲解 onSaveInstanceState、ViewModel、SavedStateHandle 的区别与协同流程，并提供配置变更示例。`
  - `请作为代码审查员，审查以下 Activity/Fragment 结构，关注生命周期/状态管理/内存泄漏风险。`
  - `根据这份周成果草稿，帮我生成一份可发布的周报（完成/问题/计划）。`
- **复盘产出**：状态管理示例代码、配置变更测试文档、APK/演示截图、周总结、`issues-week2.md`。

1. `build.gradle.kts` 中 compileSdk/minSdk/targetSdk 的取值依据是什么？如何启用 ViewBinding？
