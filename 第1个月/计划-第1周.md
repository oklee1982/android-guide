# 第1个月｜计划-第1周

## 周主题与目标
- 主题：Kotlin 语言基础 + 命令行小练习，夯实变量/函数/面向对象/集合/扩展/空安全/协程起步。
- 目标：能在 Kotlin REPL 或命令行项目中独立实现 3 个以上小脚本，覆盖输入处理、条件/循环、集合变换与简单协程调用；完成每日复盘与错题记录。
- 验收：完成 Kotlin 基础知识脑图+练习代码仓库；命令行 Demo 可读取/保存本地数据或调用简单 API Mock；形成问题清单与下一周学习卡位。

## 准备事项（周一上午前完成）
- 安装/更新 Android Studio、Kotlin CLI 编译器，配置 Gradle 与 Git（含 GitHub 私有仓库）。
- 建立仓库结构：`notes/`（讲义与复盘）、`code/kotlin-week1/`（命令行示例），README 更新周计划链接。
- 建立 AI Prompt 模板：知识点讲义、练习题、代码审查、错题复盘四套固定提示词。

## 每日节奏提醒
- 1h AI 讲义/知识点 → 4h 编码实操（跟练→独立） → 1h Bug/错题复盘 → 1h 官方文档/文章阅读 → 1h 面试题或巩固练习。
- 所有练习先写出“我已知/未知/本次验证点”，提交到周日志，便于 AI 追踪。

## 每日拆解

### 第1天（周一）｜环境+变量与类型
- **学习**：Kotlin 项目结构、main 函数、变量/常量、字符串模板、基础类型与类型推断。
- **实操**：完成“温度转换器 + 简单计算器”命令行程序，支持参数或交互输入。
- **AI 提示词**：
  1. “请分章节讲解 Kotlin 变量与类型系统，附 2 个最小示例和 3 道小测题。”
  2. “基于下述代码草稿做代码审查，关注输入校验与异常处理。”
- **复盘产出**：记录 IDE/CLI 配置步骤、常见编译错误、概念卡片 5 条。

### 第2天（周二）｜流程控制与函数
- **学习**：条件表达式、`when`、循环、函数定义/默认参数/命名参数、`Unit`、`infix`。
- **实操**：实现“待办事项 CLI”——新增/删除/过滤任务，包含 `when` + `when` 作为表达式。
- **AI 提示词**：“请按照’概念要点→最小示例→常见坑’格式输出 Kotlin when/循环/函数要点，并给 3 个命令行练习需求。”
- **复盘产出**：提交代码到仓库并让 AI 生成测试用例列表，记录 3 个可复审的问题。

### 第3天（周三）｜面向对象与数据类
- **学习**：类与构造函数、`init`、继承、`object`/单例、`data class`、`sealed class`、接口。
- **实操**：将前一天的待办程序重构为面向对象（任务仓库、命令解析器），新增“分类统计”功能。
- **AI 提示词**：“请扮演代码审查员，检查下述 Kotlin data class/继承实现的可读性与可测试性，并列出重构建议。”
- **复盘产出**：记录“OOP 重构前后差异”对比表、整理 5 个面向对象术语卡片。

### 第4天（周四）｜集合、泛型、函数式
- **学习**：`List/Set/Map`、可变与不可变、`sequence`、常用 `map/filter/reduce`、泛型约束、`inline`/`crossinline` 概念。
- **实操**：编写“图书管理 CLI”——从 JSON/CSV 读取数据（可本地文件），提供搜索/排序/筛选；用扩展函数封装常用集合操作。
- **AI 提示词**：“请根据以下集合处理需求生成 Kotlin 示例，要求包含泛型扩展函数和性能注意事项。”
- **复盘产出**：生成集合操作 Cheat Sheet，并记录 I/O + 集合的性能观察。

### 第5天（周五）｜空安全、扩展函数、包与模块
- **学习**：空安全操作符、`let/apply/run/also/with`、扩展函数/属性、包结构、可见性、`typealias`。
- **实操**：为图书管理 CLI 添加“用户偏好”配置，存储到本地 JSON；利用扩展函数封装空值处理逻辑；练习 `typealias`。
- **AI 提示词**：“请生成 5 道关于 Kotlin 空安全与扩展函数的情景题，并提供参考答案和常见错误。”
- **复盘产出**：总结空安全决策树、列出 3 个未来在 Android 中可复用的模式。

### 第6天（周六）｜协程基础与周总结
- **学习**：协程概念、`suspend`、`launch/async`、`Dispatchers`、`withContext`，结构化并发与异常捕获。
- **实操**：给图书管理 CLI 增加“网络模拟”模块（用 `delay` 模拟 API），演示与本地存储并行处理；写 2 个单元测试验证数据合并逻辑。
- **AI 提示词**：“用表格形式讲解 Kotlin 协程核心概念，并设计一个命令行练习：并行拉取两个源合并结果。”
- **复盘产出**：完成周总结模板（收获/问题/下周目标），整理错题与 Bug 列表，更新 README 的周进度。

### 第7天（周日）｜休息或轻量复习
- 30 分钟复盘本周笔记，检查仓库 README 是否同步。
- 若有精力，做 1 次面试速答：`Kotlin 变量 vs val/var`、`when` 作为表达式、`data class` 用途。
