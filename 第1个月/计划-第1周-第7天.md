# 第1个月｜第1周｜第7天

## 今日使命（休息/轻复习）
- 保持低强度复盘：整理资料、清理仓库、检查 README 与目录结构。
- 通过 30–60 分钟的复习巩固 Kotlin 基础概念与术语。
- 准备第2周预习清单：Android Studio、Activity 生命周期、ViewBinding。

## 建议安排（≤4h）
1. 30 min：整理仓库、打 tag（`week1-done`）、检查 Git 提交信息。
2. 30 min：回顾笔记/错题本，更新疑问列表。
3. 60 min：面试式自测：
   - `val` vs `var`、`const val` 场景。
   - `when` 表达式返回值、`sealed class`。
   - 集合 `map` vs `sequence` 的差异。
   - 协程基础问答。
4. 30 min：向 AI 询问“Android Studio/Activity 生命周期”速览，形成预习提纲。
5. 30 min：规划生活/休息，确保下周学习节奏。
